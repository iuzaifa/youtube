## **Java Interview Q\&A (For 1 Year Experience)**

### **Core Basics**

1. **What is Java?**
   Java is a high-level, object-oriented, platform-independent programming language.

2. **Why is Java platform independent?**
   Because Java programs compile into bytecode, which runs on the JVM across different platforms.

3. **What are JVM, JDK, and JRE?**

* **JVM**: Runs Java bytecode.
* **JRE**: JVM + libraries.
* **JDK**: JRE + development tools (compiler, debugger).

4. **What are Java’s main features?**
   OOP, platform independence, robustness, multithreading, security, portability.

5. **What are wrapper classes in Java?**
   Classes that convert primitive data types into objects (e.g., `int` → `Integer`).

---

### **OOP Concepts**

6. **What is Object-Oriented Programming?**
   Programming using objects and classes; supports encapsulation, inheritance, polymorphism, and abstraction.

7. **Explain Encapsulation.**
   Wrapping data (fields) and methods into a single unit (class), with restricted access via access modifiers.

8. **Explain Inheritance.**
   Mechanism where one class acquires properties of another class using `extends`.

9. **Explain Polymorphism.**
   Ability of a method to behave differently:

* Compile-time (method overloading).
* Runtime (method overriding).

10. **Explain Abstraction.**
    Hiding implementation details and exposing only essential features using abstract classes and interfaces.

---

### **Java Basics & Keywords**

11. **What is the difference between `==` and `.equals()`?**

* `==`: Compares memory reference.
* `.equals()`: Compares values.

12. **What is `final` in Java?**

* Variable: constant.
* Method: cannot be overridden.
* Class: cannot be inherited.

13. **What is `this` keyword?**
    Refers to the current object of a class.

14. **What is `super` keyword?**
    Refers to the parent class object; used to call parent class methods or constructors.

15. **Difference between static and non-static members?**

* Static: Belongs to class, shared across objects.
* Non-static: Belongs to instance.

---

### **Java Memory & Execution**

16. **What is the difference between Stack and Heap memory?**

* Stack: Stores method calls, local variables.
* Heap: Stores objects and instance variables.

17. **What is Garbage Collection?**
    Automatic memory management that removes unused objects.

18. **What is a Constructor in Java?**
    A special method used to initialize objects, same name as class, no return type.

19. **Difference between default and parameterized constructor?**

* Default: No arguments.
* Parameterized: Accepts arguments for initialization.

20. **What are Access Modifiers in Java?**

* `public`: Accessible everywhere.
* `protected`: Same package + subclasses.
* `default`: Same package.
* `private`: Within class only.

---

### **Strings & Collections**

21. **Difference between String, StringBuilder, and StringBuffer?**

* String: Immutable.
* StringBuilder: Mutable, not thread-safe.
* StringBuffer: Mutable, thread-safe.

22. **How many ways to create a String in Java?**
    Two: Using string literal and using `new String()`.

23. **What are Collections in Java?**
    Framework for storing and manipulating groups of objects (List, Set, Map).

24. **Difference between List, Set, and Map?**

* List: Ordered, allows duplicates.
* Set: Unordered, no duplicates.
* Map: Key-value pairs.

25. **Difference between ArrayList and LinkedList?**

* ArrayList: Fast random access, slow insertion/deletion.
* LinkedList: Fast insertion/deletion, slower access.

---

### **Advanced Basics**

26. **What is Exception Handling in Java?**
    A mechanism to handle runtime errors using `try`, `catch`, `finally`, `throw`, `throws`.

27. **Checked vs Unchecked Exceptions?**

* Checked: Compile-time (e.g., IOException).
* Unchecked: Runtime (e.g., NullPointerException).

28. **What is Multithreading in Java?**
    Concurrent execution of multiple threads within a program.

29. **Difference between process and thread?**

* Process: Independent program with its own memory.
* Thread: Lightweight unit inside a process sharing memory.

30. **What is Synchronization in Java?**
    A mechanism to control access to shared resources in multithreading, preventing race conditions.
