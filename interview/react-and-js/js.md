# **React + JavaScript Interview Q\&A (For 1 Year Experience)**

---

## **JavaScript (15 Questions)**

1. **What are the data types in JavaScript?**
   Primitive (String, Number, Boolean, Undefined, Null, BigInt, Symbol) and Non-primitive (Objects, Arrays, Functions).

2. **Difference between `var`, `let`, and `const`?**

* `var`: Function-scoped, redeclaration allowed.
* `let`: Block-scoped, no redeclaration.
* `const`: Block-scoped, cannot be reassigned.

3. **What is hoisting in JavaScript?**
   Moving variable and function declarations to the top of scope during compilation.

4. **What is the difference between `==` and `===`?**

* `==`: Compares values, type conversion allowed.
* `===`: Compares values and types (strict).

5. **What are arrow functions?**
   Short-hand syntax for functions, without their own `this`.

6. **What is the difference between function declaration and function expression?**

* Declaration: Hoisted.
* Expression: Not hoisted.

7. **What are JavaScript closures?**
   A function that has access to its outer scope variables, even after the outer function is finished.

8. **What is the difference between synchronous and asynchronous code?**

* Synchronous: Executes line by line.
* Asynchronous: Non-blocking, executed later (via callbacks, promises, async/await).

9. **What is a Promise in JavaScript?**
   An object that represents eventual completion or failure of an asynchronous task.

10. **What is async/await in JavaScript?**
    Syntactic sugar over Promises for writing cleaner asynchronous code.

11. **What is the difference between `null` and `undefined`?**

* `null`: Intentional empty value.
* `undefined`: Variable declared but not assigned a value.

12. **What is an event loop in JavaScript?**
    Mechanism that handles asynchronous tasks by managing the call stack and callback queue.

13. **What is the difference between `map()`, `forEach()`, and `filter()`?**

* `map()`: Returns a new array.
* `forEach()`: Iterates but doesn’t return.
* `filter()`: Returns new array with condition.

14. **What are template literals in JavaScript?**
    Strings enclosed in backticks `` ` ``, allowing interpolation with `${}`.

15. **What is the difference between deep copy and shallow copy?**

* Shallow copy: Copies references (changes reflect).
* Deep copy: Copies actual values (independent).

## **React (15 Questions)**

16. **What is React?**
    A JavaScript library for building user interfaces using components.

17. **What are components in React?**
    Reusable building blocks:

* Class Components
* Function Components (with hooks).

18. **What are props in React?**
    Props (properties) are read-only data passed from parent to child components.

19. **What is state in React?**
    An object that holds dynamic data inside a component.

20. **Difference between props and state?**

* Props: Passed by parent, read-only.
* State: Local, mutable inside component.

21. **What are React hooks?**
    Functions that allow using state and lifecycle in function components (`useState`, `useEffect`).

22. **What is useState in React?**
    A hook that allows you to manage component state in function components.

23. **What is useEffect in React?**
    A hook for handling side effects like API calls, subscriptions, DOM updates.

24. **Difference between controlled and uncontrolled components?**

* Controlled: Form data handled by React state.
* Uncontrolled: Form data handled by DOM.

25. **What is virtual DOM in React?**
    A lightweight copy of the real DOM used to optimize rendering.

26. **What are keys in React?**
    Unique identifiers used to track elements in lists, improving rendering efficiency.

27. **What is JSX in React?**
    A syntax extension allowing HTML-like code inside JavaScript.

28. **What is lifting state up in React?**
    Sharing state between components by moving it to the closest common parent.

29. **Difference between React Router’s BrowserRouter and HashRouter?**

* BrowserRouter: Uses HTML5 history API.
* HashRouter: Uses hash (#) in URL for routing.

30. **What is Redux in React?**
    A state management library that stores global state in a single store with predictable flow (actions → reducers → store).
